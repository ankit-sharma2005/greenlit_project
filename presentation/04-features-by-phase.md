## Status key

- **DONE** means the phase header in Progress records it as done, with any listed caveats retained.
- **PARTIAL** means the docs explicitly record only a subset or unproven runtime.
- **NOT VERIFIED** means no reliable evidence supports the claim; it is not a synonym for “probably works.”

## Documentation drift to mention in a presentation

The project spec, progress log, audit, and test suite are not perfectly synchronized. For example, the audit says Phase 10 is partial and unsupported types should be rejected, while two Phase 10 tests still assert older successful behavior. The current test output is reported separately rather than silently inheriting an older “77 passed” summary.
